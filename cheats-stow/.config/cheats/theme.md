# Look

Two themes (`gruvbox`, `monochrome`), one bar (outline).

| How | What |
|---|---|
| `Super+Alt+T` | toggle theme |
| `theme.sh gruvbox` / `monochrome` | in `~/.config/waybar/scripts/` |
| `Super+Alt+W` | wallpaper cards |
| `~/.config/waybar/scripts/wallpaper.sh random` | random wallpaper |

Wallpapers: `~/realm/builds/dotfiles-acer/wallpapers/`, active one is the `current` symlink (hyprpaper + hyprlock use it).

Colours: `themes/<theme>.*` in kitty, hypr, mako, rofi, waybar, lazygit, yazi, gtk; palettes in `starship/starship.toml`, `zsh/theme.zsh`, `nvim/lua/plugins/theme.lua`. New shells and nvim pick up a switch (`exec zsh`).
